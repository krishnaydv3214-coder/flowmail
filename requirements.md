# Functional Requirements

## FR-1

User can connect Gmail account through Corsair.

## FR-2

User can connect Google Calendar through Corsair.

## FR-3

User can view inbox.

## FR-4

User can read email threads.

## FR-5

User can send emails.

## FR-6

User can create calendar events.

## FR-7

User can update events.

## FR-8

User can search emails.

## FR-9

User can receive realtime updates through webhooks.

## FR-10

User can use AI chat to execute actions.

## FR-11

User can use keyboard shortcuts.

## FR-12

User can classify emails by priority.

# Non Functional Requirements

## Performance

* Search under 1 second
* Page load under 2 seconds

## Reliability

* 99% webhook processing success

## Security

* OAuth authentication
* Encrypted tokens
* Secure API routes

## Scalability

* Handle 10,000+ emails per user
* Support vector search

## Accessibility

* Keyboard navigation
* WCAG compliance

## Mobile Support

* Responsive layouts
* Touch-friendly controls
