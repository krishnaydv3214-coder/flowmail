# Product Requirements Document (PRD)

## Product Name

FlowMail AI

## Problem

Current email and calendar applications require too many clicks and context switching.

Users constantly:

* Search through emails for meeting details
* Open calendar separately to schedule events
* Copy information from emails into calendar invites
* Manually prioritize important emails
* Spend excessive time managing inboxes

Existing solutions focus on email organization rather than workflow execution.

## Solution

FlowMail AI combines Gmail and Google Calendar into a single AI-powered workspace.

Instead of managing emails and meetings separately, users manage:

* Conversations
* Tasks
* Meetings
* Commitments

The system uses Corsair integrations to provide realtime email and calendar access while offering workflow-focused UI improvements.

## Core Features

### Gmail Integration

* Read emails
* Search emails
* Send emails
* Draft emails
* Thread view

### Calendar Integration

* View calendar
* Create events
* Edit events
* Send invites
* Update invites

### AI Priority Inbox

Automatically classify emails:

* Critical
* Important
* Normal
* Low Priority

### Unified Action Center

Example:

Email:
"Can we meet Thursday at 9 AM?"

Actions:

* Schedule Meeting
* Reply
* Create Task

Without opening multiple screens.

### Command Palette

Keyboard-first experience.

Examples:

/email
/calendar
/schedule
/reply
/search

### Realtime Sync

Receive:

* New emails
* Calendar updates
* Meeting invitations

Through Corsair webhooks.

### Agent Chat (Bonus)

Examples:

"Send an invite to [john@example.com](mailto:john@example.com) tomorrow at 3 PM"

"Reply to Sarah and tell her I'll attend"

Agent executes actions through Corsair MCP.
