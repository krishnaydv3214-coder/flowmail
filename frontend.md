# Frontend Requirements

## Design Goal

Superhuman-inspired productivity UI.

Fast.
Minimal.
Keyboard-first.

## Pages

### Dashboard

Shows:

* Priority Emails
* Upcoming Meetings
* Pending Replies
* Action Suggestions

### Inbox

Features:

* Thread view
* AI priority badges
* Keyboard navigation
* Search

### Calendar

Features:

* Day View
* Week View
* Agenda View

### Command Palette

Shortcut:

CMD + K

Actions:

* Compose Email
* Create Meeting
* Search Email
* Search Calendar
* Open Thread

### AI Chat

Chat interface connected to Corsair MCP.

Example:

"Schedule meeting with Alex next Friday"

### Settings

* Gmail Connection
* Calendar Connection
* Webhook Status
* AI Settings

## Components

* Sidebar
* Inbox List
* Thread Viewer
* Compose Modal
* Calendar Grid
* Chat Panel
* Notification Center
* Search Overlay

## Keyboard Shortcuts

C → Compose

R → Reply

S → Search

M → Schedule Meeting

G → Go To Inbox

K → Open Command Palette
